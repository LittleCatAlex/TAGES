
# TAGES (Taiwan AI Geological Exploration System)

## 專案簡介

TAGES，用來做科展的。

---

## 安裝與執行

* **下載與建置環境**：執行 `install_env.bat` 批次檔，自動安裝相依套件與設定運行環境。
* **啟動系統**：執行 `start.bat` 批次檔，即可開始運行 TAGES 系統。

---

## 指令指南

進入系統後，支援以下指令：

| 指令                     | 功能說明                                                                        |
| :----------------------- | :------------------------------------------------------------------------------ |
| **`repl`**       | 啟動 TAGES 互動式指令介面。                                                     |
| **`fetch`**      | 從中研院地球科學網 (TEC API) 自動下載並轉檔最新震波模型資料。                   |
| **`seismic`**    | 獨立處理震波速率模型，執行深度網格內插並輸出特徵矩陣。                          |
| **`export-rqd`** | 將 Excel 鑽探檔案中的「岩石RQD值」分頁，批次匯出成乾淨的 CSV 檔。               |
| **`drilling`**   | 批次處理 JSON 鑽探紀錄，自動執行文字解碼、掛載震波資料並進行特徵對齊。          |
| **`train`**      | 讀取所有特徵矩陣，訓練「隨機森林 (Random Forest)」AI 模型並自動存檔與產出報告。 |
| **`predict`**    | 啟動互動式 AI 預測終端，手動輸入深度、Vp、Vs 即可即時預測岩石種類。             |
| **`clean`**      | 一鍵清理並刪除`data_output` 內的產出檔案（內建防呆確認機制）。                |
